A fast, dependency-free Markdown renderer that returns byte-identical HTML to marked 18.1.3 with its default options, built as a single-pass scanner with no token tree and no regular-expression backtracking in its hot paths.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
